# DART MCU 外设配置 - 移植提示词

## 核心外设清单

### CAN总线 (2个)
- **CAN1**: PD0(RX), PD1(TX) @1Mbps
  - 0x201: MotorTriggerLS (扳机丝杆)
  - 0x202: MotorLoad[0] (左装填)
  - 0x203: MotorLoad[1] (右装填)
- **CAN2**: PB12(RX), PB13(TX) @1Mbps
  - 0x208: MotorYawLS (偏航丝杆)

### UART串口 (2个)
- **USART1**: PB6(TX), PB7(RX) @100kbps, 9位偶校验 → DT7遥控器
- **USART3**: PD8(TX), PD9(RX) → 裁判系统

### PWM舵机 (7个)
1. TIM2_CH4(PA3): 左扳机舵机 (55°↔95°)
2. TIM4_CH1(PD12): 右扳机舵机 (0°↔35°)
3. TIM4_CH2(PD13): 左升降机0 (67°↔190°)
4. TIM4_CH3(PD14): 左升降机1 (67°↔190°)
5. TIM4_CH4(PD15): 右升降机0 (203°↔80°)
6. TIM5_CH1(PH10): 右升降机1 (203°↔80°)
7. TIM5_CH4(PI0): 下滑舵机 (80°↔130°)

**空闲PWM**: TIM5_CH2(PH11), TIM5_CH3(PH12), TIM12_CH1(PH6)

### GPIO关键引脚
- **输入**: PA0/PA1(上拉), PA2, PI5/PI6(TIM8输入捕获-测速仪)
- **输出**: PH4/PH5/PE11/PF14/PG1-PG8
- **USB**: PA11(DM), PA12(DP), PA8(SOF) → CDC虚拟串口
- **调试**: PA13(SWDIO), PA14(SWCLK)

### 定时器用途
- TIM1: 系统滴答
- TIM2/4/5: PWM舵机
- TIM6: 蜂鸣器音效(1kHz)
- TIM8: 测速仪输入捕获
- TIM12: 预留PWM

## 移植要点
1. **时钟**: 12MHz晶振→168MHz系统时钟
2. **中断优先级**: CAN/UART=5, 定时器=15
3. **DMA**: USART1/3使用DMA接收(双缓冲)
4. **PWM频率**: 舵机50Hz标准
5. **CAN滤波**: 掩码模式接收所有ID

## 准备新机制扩展
- 滑台电机: CAN总线
- 大摆锤电机: CAN总线
- 总线舵机: 可用PH11/PH12
- 吸盘气阀: 可用PG引脚
