# DART MCU 外设配置总结

## 芯片型号
- STM32F427IIH6 (UFBGA176封装)

## 系统时钟
- 外部晶振: 12MHz (PH0/PH1)
- 系统时钟: 168MHz
- APB1: 42MHz
- APB2: 84MHz

## 外设配置总览

### 1. CAN总线
| 外设 | 引脚 | 功能 | CAN ID | 用途 |
|------|------|------|--------|------|
| CAN1 | PD0(RX), PD1(TX) | 1Mbps | - | 内部电机控制 |
| CAN2 | PB12(RX), PB13(TX) | 1Mbps | - | 外部电机控制 |

**CAN设备列表：**
- CAN1:
  - 0x201: MotorTriggerLS (扳机丝杆电机)
  - 0x202: MotorLoad[0] (左侧装填电机)
  - 0x203: MotorLoad[1] (右侧装填电机)
- CAN2:
  - 0x208: MotorYawLS (偏航丝杆电机)

### 2. UART串口
| 外设 | 引脚 | 配置 | 用途 |
|------|------|------|------|
| USART1 | PB6(TX), PB7(RX) | 100kbps, 9位, 偶校验 | 遥控器接收(DT7) |
| USART3 | PD8(TX), PD9(RX) | 异步模式 | 裁判系统通信 |

### 3. PWM舵机控制 (7个舵机)
| 舵机索引 | 定时器通道 | 引脚 | 功能 | 角度范围 |
|----------|------------|------|------|----------|
| trigger_servo[0] | TIM2_CH4 | PA3 | 左侧扳机舵机 | 55°(装填) ↔ 95°(触发) |
| trigger_servo[1] | TIM4_CH1 | PD12 | 右侧扳机舵机 | 0°(装填) ↔ 35°(触发) |
| trigger_servo[2] | TIM4_CH2 | PD13 | 左侧升降机舵机0 | 67°(下降) ↔ 190°(上升) |
| trigger_servo[3] | TIM4_CH3 | PD14 | 左侧升降机舵机1 | 67°(下降) ↔ 190°(上升) |
| trigger_servo[4] | TIM4_CH4 | PD15 | 右侧升降机舵机0 | 203°(下降) ↔ 80°(上升) |
| trigger_servo[5] | TIM5_CH1 | PH10 | 右侧升降机舵机1 | 203°(下降) ↔ 80°(上升) |
| trigger_servo[6] | TIM5_CH4 | PI0 | 下滑舵机 | 80°(切断) ↔ 130°(滑动) |

**空闲PWM通道：**
- TIM5_CH2 (PH11) - 可用
- TIM5_CH3 (PH12) - 可用
- TIM12_CH1 (PH6) - 可用

### 4. GPIO输入
| 引脚 | 配置 | 用途 |
|------|------|------|
| PA0 | 输入，上拉 | 限位开关/通用输入 |
| PA1 | 输入，上拉 | 限位开关/通用输入 |
| PA2 | 输入，无上拉 | 通用输入 |
| PI5 | TIM8_CH1输入捕获 | 测速仪开始信号 |
| PI6 | TIM8_CH2输入捕获 | 测速仪结束信号 |

### 5. GPIO输出
| 引脚 | 初始状态 | 用途 |
|------|----------|------|
| PH4 | 低电平 | 通用输出 |
| PH5 | 低电平 | 通用输出 |
| PE11 | 低电平 | 通用输出 |
| PF14 | 高电平 | 通用输出 |
| PG1-PG8 | 高电平 | 状态指示灯/控制信号 |

### 6. USB设备
| 引脚 | 功能 | 用途 |
|------|------|------|
| PA11 | USB_OTG_FS_DM | USB数据- |
| PA12 | USB_OTG_FS_DP | USB数据+ |
| PA8 | USB_OTG_FS_SOF | USB帧开始 |
| 功能 | USB CDC虚拟串口 | ROS2通信/调试 |

### 7. 定时器
| 定时器 | 功能 | 用途 |
|--------|------|------|
| TIM1 | 系统滴答定时器 | HAL_IncTick() |
| TIM2 | PWM输出 | 舵机0控制 |
| TIM4 | PWM输出 | 舵机1-4控制 |
| TIM5 | PWM输出 | 舵机5-6控制 |
| TIM6 | 基础定时器 | 蜂鸣器音效(1kHz) |
| TIM8 | 输入捕获 | 测速仪(开始/结束时间) |
| TIM12 | PWM输出 | 预留 |

### 8. 其他外设
| 外设 | 功能 | 用途 |
|------|------|------|
| DMA | 数据传输 | USART1/3 DMA接收 |
| RNG | 随机数生成 | 硬件随机数 |
| FreeRTOS | 实时操作系统 | 任务调度 |

### 9. 调试接口
| 引脚 | 功能 |
|------|------|
| PA13 | SWDIO |
| PA14 | SWCLK |

## 新装填机制所需外设（规划中）
根据dart_config.h注释，需要添加：
1. **滑台电机** - CAN总线电机
2. **大摆锤旋转电机** - CAN总线电机  
3. **总线舵机** - PWM舵机（可用PH11/PH12）
4. **吸盘气阀** - GPIO输出控制（可用PG引脚）

## 移植注意事项
1. **时钟配置**：确保168MHz系统时钟正确配置
2. **中断优先级**：CAN/UART使用优先级5，定时器使用优先级15
3. **DMA配置**：USART使用DMA接收，注意双缓冲机制
4. **PWM频率**：舵机使用50Hz标准频率
5. **CAN滤波**：配置为接收所有ID（掩码模式）

## 代码结构提示
- 电机控制：`motor.h/cpp`, `motor_controller.h/cpp`

- 状态机：`state_machine.h/cpp`, `OpenFSM`
- 通信：`dbus.h/cpp`, `judge_receive.h/cpp`
- 配置：`dart_config.h`

## 编译配置
- 编译器：arm-none-eabi-gcc/g++
- 优化级别：Debug(-Og), Release(-Ofast)
- 浮点单元：硬浮点(-mfloat-abi=hard -mfpu=fpv4-sp-d16)
- CPU：Cortex-M4(-mcpu=cortex-m4 -mthumb)
